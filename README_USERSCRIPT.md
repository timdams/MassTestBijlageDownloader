# Userscript Installatie Handleiding

Als u de Chrome-extensie niet mag installeren, kunt u dit script gebruiken.

## 1. Tampermonkey Installeren

U heeft een "Userscript Manager" nodig. Dit is een veilige, erkende extensie die vaak wel toegestaan is.
*   **Chrome / Edge**: [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) of [Violentmonkey](https://chrome.google.com/webstore/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag).

## 2. Het script installeren

1.  Klik op het icoon van Tampermonkey in uw browserbalk.
2.  Kies **Nieuw script toevoegen** (Create a new script).
3.  Verwijder alle tekst die er staat.
4.  Open het bestand `userscript.js` uit deze map met Kladblok (Notepad).
5.  Kopieer **alle** tekst en plak het in de editor van Tampermonkey.
6.  Druk op `Ctrl+S` (Opslaan) of klik op Bestand > Opslaan.

## 3. Gebruik

1.  Ga naar de resultatenpagina op `toets.ap.be`.
2.  Er verschijnt nu automatisch een **Rode Knop** rechtsonder: "Download Zips (X)".
3.  Klik erop om alles te downloaden.

*(Let op: de eerste keer vraagt Tampermonkey misschien toestemming om bestanden te downloaden. Klik op 'Altijd toestaan'.)*
